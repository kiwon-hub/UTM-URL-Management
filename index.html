생성된 URL

내가 만든 URL 기록

이 목록은 지금 이 브라우저에서 직접 생성한 URL만 기록합니다. 전체 조합을 한 번에 보여주는 목록이 아니므로, 원하는 URL을 위 단계에서 다시 선택해 만들어야 합니다.

    UTM 파라미터 규칙

    utm_source
    트래픽이 어느 매체/플랫폼에서 왔는지 — 예: google, naver, kakao, meta
    utm_medium
    어떤 방식의 유입인지 (마케팅 채널 유형) — 예: cpc(검색광고), display(배너광고), paid_social(소셜광고). 채널이 정해지면 값이 고정되며, 관리 페이지에서 임의로 바꾸지 않습니다.
    utm_campaign
    무슨 목적의 광고였는지 (자유롭게 짓는 프로젝트명) — 같은 채널이라도 "기본 / 무료샘플신청 / 심토스 전시회"처럼 프로젝트가 바뀌면 campaign 값만 바뀝니다. 예: 2026_freesample_promotion
    utm_content
    소재 구분 (날짜, 소재명, 게재위치 등). 선택 입력입니다.

    "광고니까 utm_source=ads"가 맞을까?

    흔히 하는 오해입니다. "광고냐 아니냐"는 utm_medium이 답하는 질문이고(cpc/display/paid_social 자체가 이미 "유료광고"라는 뜻), utm_source는 "어느 플랫폼이냐"를 답해야 하는 항목입니다.

    구글·네이버·카카오·메타 광고를 전부 utm_source=ads로 넣으면 GA4가 이 넷을 구분하지 못합니다. ads / kakao_keyword와 ads / naver_keyword_ads는 source가 같아서, GA4의 자동 채널 분류(Paid Search, Paid Social 등)가 제대로 인식하지 못하고 "Unassigned"로 빠질 수 있습니다. "어느 플랫폼이 효과 좋은지 보고 싶다"는 목적 자체가 흔들리는 셈입니다.

    항목넣을 값예시
    utm_source실제 플랫폼명google, naver, kakao, meta, simtos(전시회 QR), kiwontools(자사 QR)
    utm_mediumGA4가 알아보는 표준 채널 유형cpc(검색광고), display(배너/카카오모먼트), paid_social(메타)
    utm_campaign자유형식 캠페인명 (연도·목적·리마케팅 여부 등 세부정보는 여기로)2026_freesample_promotion, simtos2026, endmill_remarketing_2026q1

    현재 이 도구의 "URL 생성" 탭은 기존 대장(엑셀)에 있던 utm_source=ads 방식의 값을 그대로 따르고 있습니다. 위 권장 방식으로 새로 설계하고 싶다면 담당자와 상의해 데이터를 다시 정리하는 작업이 필요합니다.

    메타(페이스북/인스타그램) 광고 — 매체별로 무엇이 바뀌는가

    현재 대장에는 메타 광고가 utm_source=ads(또는 심토스 프로모션일 때 simtos) / utm_medium=meta_ads 로 고정되어 있고, 페이스북과 인스타그램을 구분하지 않았습니다.

    메타는 utm_source/utm_medium 자체를 자동으로 바꿔주지 않습니다. 페이스북/인스타그램을 구분하려면 Meta 광고관리자(Ads Manager)의 URL 매개변수 입력란에 아래와 같은 동적 매크로를 넣어 utm_content(또는 utm_term)에 자동으로 값이 채워지도록 해야 합니다.

    매크로치환되는 값용도
    {{site_source_name}}fb / ig / an / msg 등페이스북·인스타그램·오디언스 네트워크·메신저 구분 (가장 단순)
    {{placement}}facebook_feed, instagram_story, instagram_reels, instagram_stream 등세부 게재 위치까지 구분
    {{campaign.name}}캠페인명캠페인 자동 기록
    {{adset.name}} / {{ad.name}}광고그룹명 / 소재명광고그룹·소재 자동 기록

    권장 방식: utm_source / utm_medium은 기존 값(ads 또는 simtos / meta_ads)을 그대로 두고, utm_content에 {{site_source_name}} 또는 {{site_source_name}}_{{placement}}를 넣습니다. 이렇게 만든 URL을 그대로 Meta 광고관리자의 "URL 매개변수" 항목에 붙여넣으면, 실제 노출 시 자동으로 fb/ig 값이 채워집니다. "URL 생성" 탭에서 채널을 메타 광고로 선택하면 이 옵션을 바로 고를 수 있습니다.

    이 페이지는 "전체보기"를 제공하지 않습니다

    기존 대장을 한 화면에 모두 펼쳐두면 실수로 잘못된 URL을 복사하기 쉽습니다. 그래서 이 페이지는 사이트 → 플랫폼 → 광고 종류 → 프로젝트 → 페이지 순서로만 골라 URL을 만들도록 제한했고, 만든 URL은 "내가 만든 URL 기록"에만 남습니다.
