# UTM URL 관리 페이지

기원엠알오(kiwonmro.com) / 기원툴스(kiwontools.com)에서 쓰던 UTM 대장(엑셀)을 대체하기 위한
정적 웹페이지입니다. 빌드나 서버 없이 `index.html`을 열면 바로 동작합니다.

## 사용 방법

로컬에서 열어보려면 정적 파일 서버로 실행하세요 (파일을 브라우저로 바로 열면 일부 브라우저에서
로컬 스토리지가 제한될 수 있습니다).

```bash
python3 -m http.server 8080
# http://localhost:8080 접속
```

GitHub Pages 등 정적 호스팅에 그대로 올려도 동작합니다.

## 설계 원칙 (요청 사항 반영)

1. **전체보기 없음** — 기존 대장을 한 화면에 다 펼쳐두면 실수로 엉뚱한 URL을 복사하기 쉬워서,
   `사이트 → 채널 → 프로젝트 → 랜딩 페이지` 순서로만 골라 URL을 만들도록 마법사(wizard) 형태로
   제한했습니다. 직접 만든 URL만 "내가 만든 URL 기록"에 남습니다(브라우저 로컬 저장).
2. **utm_source / utm_medium은 채널 선택 시 기존 값으로 고정**되고 읽기 전용으로 표시됩니다.
   `utm_campaign`만 프로젝트(기본/무료샘플신청/심토스 전시회 등)에 따라 바뀝니다.
   목록에 없는 새 프로젝트는 "+ 새 프로젝트" 옵션으로 추가할 수 있는데, 이때도 반드시 기존
   설정 중 하나를 골라 source/medium을 유지하고 campaign 값만 새로 입력하게 되어 있습니다.
3. **메타(페이스북/인스타그램) 광고**는 utm_source/medium만으로는 두 매체를 구분할 수 없어서,
   "가이드" 탭에 Meta 동적 URL 매개변수(`{{site_source_name}}`, `{{placement}}` 등)를 이용한
   구분 방법을 정리해 두었고, "URL 생성" 탭에서 채널을 메타 광고로 선택하면 바로 적용할 수
   있습니다.

## 파일 구성

- `index.html` — 페이지 구조 (URL 생성 탭 + 가이드 탭)
- `styles.css` — 스타일
- `data.js` — 기존 UTM 대장(엑셀)에서 추출한 사이트/채널/프로젝트/랜딩페이지 데이터
- `app.js` — 단계별 선택 로직과 URL 생성/기록 로직

## 데이터 갱신

새 채널이나 프로젝트가 생기면 `data.js`의 해당 사이트 `channels` 배열에 항목을 추가하면
됩니다. `medium`은 채널 전체에 고정값을 둘 수도 있고, variant(프로젝트)마다 다르게 둘 수도
있습니다(예: 리마케팅 여부에 따라 medium이 달라지는 경우).
